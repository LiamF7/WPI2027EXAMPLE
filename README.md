*Training/template repository for a frc robot utilizing WPILib Alpha 2027, along with team 4068's libraries*
- The example robot is modeled after a robot with an elevator, pivoting arm, and manipulator roller.
- Mechanisms extend 4068's BearMechanism class.
- "Point to point" autonmous pathing via B-line.
- State machine control approach (via 4068's BearState) is used.
  > Mechanism level states with overall management from SuperState
